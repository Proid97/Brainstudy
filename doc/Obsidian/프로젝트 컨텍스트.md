# 프로젝트 컨텍스트

## 목적
- 언어기관해부생리 수업의 '뇌' 파트를 기초부터 심화까지, 전문가 수준으로 배우는 1:1 수업.

## 진행 방식
- 강의마다 설명 → 임상 연결 → 확인 문제.
- 학생이 답하면 채점·보충.
- 강의 노트는 강마다 하나씩 만들고 이 노트에서 링크.

## 맥락 읽는 법
- 이 노트 → 필요한 강의 노트만 읽기.
- 새 작업 전 [[실수와 교훈]] 먼저 읽기.

## 현재 진도
- 1강 진행함, 확인 문제 답 기다리는 중.
- 학생 교재·시험 일정은 아직 모름(물어봄).
