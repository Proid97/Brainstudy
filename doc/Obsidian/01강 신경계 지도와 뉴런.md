# 01강 신경계 지도와 뉴런

상위: [[프로젝트 컨텍스트]] | 전체 목차: [[커리큘럼]]

## 신경계 구분
- 중추(CNS) = 뇌 + 척수
- 말초(PNS) = 뇌신경 12쌍 + 척수신경 31쌍
- 체성 vs 자율(교감·부교감)
- 들신경(구심, afferent, 감각, 몸→뇌) vs 날신경(원심, efferent, 운동, 뇌→몸)
- 암기: Afferent Arrives, Efferent Exits
- 말 산출 근육(입술·혀·후두)은 뇌신경 담당 → 08강

## 방향
- 부리쪽(rostral) / 꼬리쪽(caudal)
- 등쪽(dorsal) / 배쪽(ventral)
- 안쪽(medial) / 가쪽(lateral)
- 같은쪽(ipsilateral) / 반대쪽(contralateral)
- 뇌축은 중간뇌 부근에서 꺾임 → 대뇌에서 dorsal = 위(superior), 척수에서 dorsal = 뒤(posterior)

## 단면

|---|---|---|
| 시상면(sagittal) | 좌우 | 정중시상면은 두 반구 사이 |
| 관상면(coronal) | 앞뒤 | |
| 수평면(horizontal/axial) | 위아래 | |

## 뉴런
- 가지돌기(받음) → 세포체(통합) → 축삭둔덕(발화 결정) → 축삭(전달) → 축삭종말(시냅스)
- 말이집(myelin) = 전선 피복. 랑비에결절에서 도약전도 → 빠름
- 종류: 다극(운동뉴런) / 양극(망막·나선신경절) / 거짓홑극(일반 감각뉴런)

## 신경교세포
| 세포 | 위치·역할 |
|---|---|
| 별아교세포(astrocyte) | 영양, 혈뇌장벽 지원, 흉터 |
| 희소돌기아교세포(oligodendrocyte) | CNS 말이집, 하나가 여러 축삭 |
| 슈반세포(Schwann) | PNS 말이집, 하나가 한 마디, 재생 도움 |
| 미세아교세포(microglia) | 면역·청소 |
| 뇌실막세포(ependymal) | 뇌실 벽, 맥락얼기에서 뇌척수액 생산 관여 |

## CNS vs PNS
| 항목 | CNS | PNS |
|---|---|---|
| 세포체 모임 | 핵(nucleus) | 신경절(ganglion) |
| 축삭 다발 | 로(tract) | 신경(nerve) |
| 말이집 | 희소돌기아교세포 | 슈반세포 |
- 회색질 = 세포체, 백질 = 말이집 축삭

## 임상 연결
- 다발경화증(MS) = CNS 말이집 손상 → 혼합형(경직+실조) 마비말장애 흔함
- 길랭-바레 증후군 = PNS 말이집 손상 → 이완형 마비말장애 가능
- 왼쪽 반구 손상 → 오른쪽 몸 마비(반대쪽) + 실어증
