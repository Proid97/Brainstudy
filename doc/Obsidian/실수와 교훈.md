# 실수와 교훈

실수를 누적 기록. 새 작업 전 먼저 읽기. (상위: [[프로젝트 컨텍스트]])

## 형식
각 항목은 3줄:
- 무엇이 잘못됐나
- → 왜 그랬나
- → 다음에 어떻게 하나

## 기록
- 사용자 지침에 경로가 doc/Obsidian 과 Docs/Obsidian 두 가지로 적혀 있어 doc/Obsidian 하나로 통일함.

### 1. 교재 확인 없이 일반 커리큘럼부터 만듦 (2026-11-27)
- 무엇이 잘못됐나: 사용자 교재를 묻기 전에 일반 신경해부 커리큘럼과 1강을 만들어 "원하던 내용이 아니다"는 답을 받음.
- → 왜 그랬나: "기초부터 심화까지"라는 말만 보고 범위를 짐작함. 교재 질문을 맨 끝에 미룸.
- → 다음에 어떻게 하나: 수업·정리 요청은 교재·범위·시간을 먼저 확인하고, 교재 내용을 기준으로 짠다.

### 2. Google Drive 접속 차단
- 무엇이 잘못됐나: 기본 환경 네트워크가 drive.google.com을 막아 파일을 못 받음.
- → 왜 그랬나: Default 환경은 허용 호스트가 비어 있음.
- → 다음에 어떻게 하나: 이 저장소는 brainstudy 환경(Drive 호스트 허용)에서 작업. 큰 파일은 drive.usercontent.google.com/download?id=...&confirm=t 로 받는다.
