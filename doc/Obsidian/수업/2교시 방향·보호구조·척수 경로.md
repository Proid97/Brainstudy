# 2교시. 방향·보호구조·척수 경로 (교재 p.40–47 · 권장 35분)
상위: [[프로젝트 컨텍스트]] · [[커리큘럼]] · 이전: [[1교시 신경계 큰 그림]] · 다음: [[3교시 대뇌겉질 엽과 이랑]]

## 이번 시간 목표
- 뇌실 4개의 이름·순서와 뇌척수액의 생성/흡수를 그림으로 설명한다.
- 뇌막 3층의 순서, 천막상/천막하 구분, 두개와 3개를 안다.
- 방위·단면 용어와 척수 단면, 상행(감각)/하행(운동) 경로를 구분한다.

## 핵심 개념

### 1) 척수의 단면 (p.40) — 그림 3-5
- 척수 = H자형 **회백질** + 이를 둘러싼 **백질**.
- 회백질: 등쪽 **후각**(감각신경 전달), 배쪽 **전각**(운동신경 전달).
- 백질은 3영역: 등쪽부터 **후주 → 측주 → 전주**.
- 라벨: 백질, 회백질, 후각, 후주, 측주, 전주, 전각, 중심관, 후근, 전근, 척수신경, 감각신경, 운동신경, 피부, 근육.

| 구조 | 방향 | 성질 |
|---|---|---|
| 후근 → 후각 | 등쪽 | 감각, 상행성 |
| 전각 → 전근 | 배쪽 | 운동, 하행성 |

### 2) 두개와 (p.40) — 그림 3-6
- 두개골 바닥 = **전두개와 + 중두개와 + 후두개와**.
- 후두개와 가운데에 **대후두공**이 있다 (척수가 통과 [불확실]).

### 3) 뇌막의 구조 (p.41) — 그림 3-7
- 뇌막 3층 (바깥 → 안): **① 경막 → ② 거미막 → ③ 연막**.
- 라벨: 두개골, 경막외강, 경막, 경막하강, 거미막, 거미막하강, 거미막그물, 연막, 거미막 육아, 대뇌낫, 대뇌피질.

```
두개골 → 경막외강 → 경막 → 경막하강 → 거미막 → 거미막하강(거미막그물) → 연막 → 대뇌피질
```

### 4) 천막상 구조와 천막하 구조 (p.41) — 그림 3-8
- **소뇌천막**을 기준으로 나눈다.

| 구분 | 구조 |
|---|---|
| 천막상 구조 (위) | 대뇌 |
| 소뇌천막 | 경계 |
| 천막하 구조 (아래) | 소뇌 + 뇌간 |

### 5) 뇌실의 구조 (p.42) — 그림 3-9
- 뇌실 = 좌우 1쌍 **외측뇌실** + **제3뇌실** + **제4뇌실**.
- 제3뇌실과 제4뇌실 사이의 좁은 관 = **뇌수도관**.
- 외측뇌실 부위: 몸체, 전각, 후각, 하각. 외측뇌실과 제3뇌실 사이 = 뇌실사이구멍.
- 제4뇌실 아래로 **중심관**(척수)이 이어진다.
- 정중시상면 영문 라벨: Corpus callosum, Thalamus, Cerebral aqueduct, Midbrain, Fourth ventricle, Cerebellum, Pons, Medulla, Cerebral hemisphere, Choroid plexus of third ventricle, Interventricular foramen, Septum pellucidum, Hypothalamus.
- 순서: 외측뇌실 → (뇌실사이구멍) → 제3뇌실 → (뇌수도관) → 제4뇌실 → 중심관.
- 필기: 제4뇌실 = 소뇌 쪽. 제3뇌실·뇌수도관 별표. 한글 병기: 뇌수도관, 제3뇌실, 제4뇌실, 중뇌, 소뇌, 뇌교, 뇌간(Medulla 쪽).

### 6) 뇌실과 뇌척수액 (p.43) — 그림 3-10
- 뇌척수액은 외측뇌실, 제3뇌실, 제4뇌실의 **맥락얼기**에서 만들어진다.
- 라벨: 외측뇌실 맥락얼기, 거미막 육아, 제3뇌실 맥락얼기, 제4뇌실 맥락얼기.
- 흡수는 **거미막 육아**에서 일어난다 (필기: 흡수 [불확실]).
- 만들어진 양 = 흡수되는 양. 불균형(생성 ↑ 또는 흡수 ↓)이면 **수두증(hydrocephalus)**. 압력 ↑ → 호흡·뇌 기능 ↓ [불확실].

### 7) 중추신경계의 방위 (p.43) — 그림 3-11
- 뇌와 척수는 **T자 형태의 신경축**이다.
- 앞뒤는 대뇌의 **전두극**과 **후두극**을 기준, 아래는 척수 위치를 기준으로 한다.
- 라벨: 전두극, 후두극, 부리쪽·앞쪽, 위쪽, 아래쪽, 등쪽, 배쪽, 앞쪽, 뒤쪽, 꼬리쪽, 배쪽·앞쪽, 등쪽·뒤쪽.

| 용어 | 뜻 |
|---|---|
| 등쪽 (D) / 뒤쪽 (P) | 등 쪽 |
| 배쪽 (V) / 앞쪽 (A) | 배 쪽 |
| 부리쪽 | 앞쪽(머리 앞쪽) |
| 꼬리쪽 | 꼬리 방향 |
| 위쪽 / 아래쪽 | 위 / 아래 |

### 8) 단면 (p.44) — 그림 3-12
- 뇌는 절단 방향에 따라 **축절면(수평면)**, **관상면**, **(정중)시상면**.
- 축절면 = 수평면에 각을 둔 단면. (정중)시상면 = 좌우 단면 (필기).
- 하단 그림 A, B, C 영문 라벨:
  - Olfactory organs, Eye, Spinal cord.
  - **Forebrain (Prosencephalon)**: Telencephalon, Diencephalon.
  - **Midbrain (Mesencephalon)**.
  - **Hindbrain (Rhombencephalon)**: Pons, cerebellum (Metencephalon), Medulla oblongata (Myelencephalon).
  - Lateral ventricle, III ventricle, Cerebral aqueduct, IV ventricle, Rostral choroid plexus, Caudal choroid plexus.
  - C: Lateral ventricle, III ventricle, Choroid plexus of lateral ventricle, Cerebral aqueduct, IV ventricle, Choroid plexus of IV ventricle.

| 발생 구분 | 구조 |
|---|---|
| Forebrain | 종뇌 + 간뇌 |
| Midbrain | 중뇌 |
| Hindbrain | 뇌교 + 소뇌 (metencephalon), 연수 (myelencephalon) |

### 9) 뇌 아랫면과 하행 운동 경로 (p.45)
- 뇌 아랫면 라벨: Cerebral hemisphere (대뇌반구), Hypothalamus, Pons, Medulla, Cerebellum.
- **Descending Motor Pathways** 라벨: Leg, Hand, Face, Motor cortex, Internal capsule, Corticobulbar fibres, Corticospinal fibres, Motor cranial nerve fibres, Decussation of pyramids, Motor spinal nerve fibres.

```
Motor cortex (Face/Hand/Leg) → Internal capsule
  ├ Corticobulbar fibres → Motor cranial nerve fibres (뇌신경 운동)
  └ Corticospinal fibres → Decussation of pyramids → Motor spinal nerve fibres
```

### 10) 상행 감각 경로와 피부분절 (p.46)
- **Ascending Sensory Pathways** 라벨: Ventral posterior nucleus of thalamus, Leg, Hand, Face, Somatosensory cortex, Trigeminal ganglion, Trigeminal nerve (Touch, Pain/temperature), Medial lemniscus, Pons, Medulla, Dorsal columns, Spinal nerve (Touch/proprioception, Pain/temperature), Spinothalamic tract, Dorsal root ganglion, Spinal cord.

| 경로 | 전달 감각 |
|---|---|
| Dorsal columns → Medial lemniscus | Touch / proprioception |
| Spinothalamic tract | Pain / temperature |
| Trigeminal nerve → Trigeminal ganglion | Touch, Pain/temperature (얼굴) |

- 흐름: 말초(Dorsal root ganglion / Trigeminal ganglion) → 척수·뇌간 → 시상 Ventral posterior nucleus → Somatosensory cortex.
- **Dermatome(피부분절)**: 인체 전면(A)·후면(B) 피부분절 그림, C2 ~ S5 등 분절 번호 표기 (세부 번호는 교재 그림 확인).

### 11) 척수 단면 참고 (p.47)
- 라벨: Dorsal horn, Lateral horn, White matter, Central canal, Dorsal root ganglion, Grey matter, Ventral horn.
- 감각: Afferent neurone (cell body) → Dorsal root of spinal nerve.
- 운동: Efferent neurone (cell body) → Ventral root of spinal nerve. 합쳐져 Spinal nerve.

| | 신경세포 | 방향 | 근 | 각 |
|---|---|---|---|---|
| 감각 | Afferent | 상행(ascending) | 후근 | Dorsal horn |
| 운동 | Efferent | 하행(descending) | 전근 | Ventral horn |

## ⭐ 필기·강조 포인트
- p.40: 후각 = 감각 = 상행성, 전각 = 운동 = 하행성. 그림 3-6 = "두개골 바닥".
- p.41: 뇌막 3층 순서 ① 경막 ② 거미막 ③ 연막 (바깥 → 안). 천막상(대뇌) / 천막하(소뇌, 뇌간) 밑줄, 소뇌천막 경계 빨간 표시.
- p.42: **제3뇌실, 뇌수도관** 별표 + 형광펜. 제4뇌실 = 소뇌 쪽. **"각 그림들의 순서적 위치 파악하기."**
- p.43: 맥락얼기에서 뇌척수액 생성 (밑줄). 생성량 = 흡수량, 불균형 시 수두증.
- p.44: 그림 3-12 별표. 세 단면(축절면·관상면·정중시상면) 형광펜.
- p.47: Afferent = 감각 = 상행, Efferent = 운동 = 하행. (참고 표시)

## 🧠 이해의 열쇠
- 뇌막 3층과 뇌척수액은 뇌를 감싸 보호하는 방패다. 뇌척수액이 뇌를 띄워 충격을 줄인다 [보충].
- 흐름이 막히거나 흡수가 안 되면 압력이 올라 수두증이 된다 → 뇌 기능과 호흡 영향.
- 하행 운동 경로: 얼굴(Face)은 corticobulbar를 통해 뇌신경 운동핵으로 간다. [보충] 말·삼킴 근육은 뇌신경이 지배하므로 SLP에서 매우 중요하다.
- 상행 감각 경로: 얼굴 감각은 삼차신경(Trigeminal)이 전달한다. [보충] 구강 감각은 말 명료도·삼킴과 관련된다.
- Decussation of pyramids(피라미드 교차)에서 경로가 교차한다. [보충] 그래서 한쪽 대뇌 손상은 반대쪽 몸 증상으로 나타나는 경우가 많다.
- 소뇌천막 위/아래 구분은 병변 위치(대뇌 vs 후두개와)를 말할 때 쓴다 [보충].

## 🔑 암기 장치
- 뇌막: "경·거·연" (딱딱한 것부터 안쪽으로).
- 뇌실 순서: 외측 → 3 → 수도관 → 4 → 중심관. ("외삼수사중")
- 후주·측주·전주 = 등 → 배. 후각=감각, 전각=운동 ("후감 전운").
- Afferent = Arrive(도착, 감각 → 중추), Efferent = Exit(출발, 운동).
- 두개와: 전·중·후 순서로 앞에서 뒤. 대후두공은 후두개와.

## ⚠️ 헷갈리는 함정
- 후각(dorsal horn, 척수 회백질) vs 후각(嗅覺, 냄새). 한자·뜻이 다르다. 척수의 후각 = 등쪽 뿔.
- 후각/전각(회백질) vs 후주/측주/전주(백질): 각 = 회백질, 주 = 백질.
- 경막외강 vs 경막하강 vs 거미막하강: 뇌척수액은 **거미막하강**에 있다 [보충].
- 천막상 = 대뇌, 천막하 = 소뇌 + 뇌간.
- 중심관(척수) vs 뇌수도관(중뇌): 이름이 비슷하지만 위치가 다르다.
- 부리쪽(앞) vs 꼬리쪽(뒤/아래). 앞쪽(배쪽)과 부리쪽을 구분하라.
- 축절면(수평면) vs 관상면 vs 시상면.
- Corticobulbar(뇌신경으로) vs Corticospinal(척수로).

## ✏️ 확인 문제
1. 척수 회백질에서 감각을 전달하는 부위와 운동을 전달하는 부위는?
> [!answer]- 정답
> 감각 = 후각(등쪽, 상행성). 운동 = 전각(배쪽, 하행성).

2. 척수 백질의 세 영역을 등쪽부터 쓰라.
> [!answer]- 정답
> 후주, 측주, 전주.

3. 뇌막 3층을 바깥에서 안쪽으로 쓰라.
> [!answer]- 정답
> 경막, 거미막, 연막.

4. 천막상 구조와 천막하 구조에 속하는 것은?
> [!answer]- 정답
> 천막상 = 대뇌. 천막하 = 소뇌 + 뇌간. 경계 = 소뇌천막.

5. 뇌실 4개(5구조)의 순서와 연결 구조를 쓰라.
> [!answer]- 정답
> 외측뇌실(좌우 1쌍) → 뇌실사이구멍 → 제3뇌실 → 뇌수도관 → 제4뇌실 → 중심관.

6. 뇌척수액은 어디서 만들어지고 어디서 흡수되는가?
> [!answer]- 정답
> 외측·제3·제4뇌실의 맥락얼기에서 생성. 거미막 육아에서 흡수. 불균형 시 수두증.

7. 두개와 3개와 대후두공의 위치는?
> [!answer]- 정답
> 전두개와, 중두개와, 후두개와. 대후두공은 후두개와 가운데.

8. 그림 3-11에서 뇌와 척수를 무엇이라 표현하며 앞뒤 기준 극은?
> [!answer]- 정답
> T자 형태의 신경축. 앞뒤 기준 = 전두극과 후두극.

9. 얼굴 운동 명령이 대뇌에서 뇌신경으로 가는 경로 이름은? (그림 라벨)
> [!answer]- 정답
> Motor cortex → Internal capsule → Corticobulbar fibres → Motor cranial nerve fibres. (Corticospinal은 척수로 감.)

10. 상행 감각 경로에서 Touch/proprioception과 Pain/temperature를 각각 전달하는 경로는?
> [!answer]- 정답
> Touch/proprioception = Dorsal columns → Medial lemniscus. Pain/temperature = Spinothalamic tract. 둘 다 시상 Ventral posterior nucleus → Somatosensory cortex.
