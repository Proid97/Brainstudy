# 3교시. 대뇌겉질 엽과 이랑 (교재 p.49–52 · 권장 30분)
상위: [[프로젝트 컨텍스트]] · [[커리큘럼]] · 이전: [[2교시 방향·보호구조·척수 경로]] · 다음: [[4교시 대뇌 속구조]]

## 이번 시간 목표
- 대뇌겉질을 4개 엽으로 나누는 기준선(중심고랑, 실비안종렬, 두정후두고랑)을 그림에서 짚는다.
- 엽별 기능과 이랑(gyrus) 이름을 라벨 그대로 외운다.
- 하전두이랑의 덮개부 3부분과 뇌섬, 변연계, 뇌 기저면 라벨을 구분한다.

## 핵심 개념

### 1. 기본 용어 (p.49 필기)
| 용어 | 뜻 |
|---|---|
| 이랑 (gyrus) | 올라온 부분 |
| 고랑 (sulcus) | 들어간 부분 |
| 종렬 (fissure) | 깊고 큰 고랑 (교재 필기 [불확실]) |

- 위치나 모양은 개인차가 약간 있다.

### 2. 그림 4-1 좌뇌 외측면: 엽 나누기 (p.49)
| 경계 | 나누는 엽 |
|---|---|
| 중심고랑 (central sulcus) | 앞 = 전두엽 / 뒤 = 두정엽 |
| 실비안종렬 (Sylvian fissure) = 외측고랑 | 측두엽을 전두엽·두정엽에서 분리 |
| 두정후두고랑 + 후두앞패임 (preoccipital notch) | 후두엽을 다른 엽에서 분리 |
| 대뇌종렬 | 좌우 대뇌 반구를 나눔 |

- 그림 라벨: 대뇌종렬, 중심고랑, 두정후두고랑, 전두엽, 두정엽, 측두엽, 후두엽, 실비안종렬(외측고랑), 후두앞패임.

### 3. 엽별 기능 (p.49 필기)
| 엽 | 기능 |
|---|---|
| 전두엽 | 사고력, 문제해결, 추리, 판단, 욕구조절 |
| 측두엽 | 청각 이해 |
| 후두엽 | 시각 이해 |
| 두정엽 | 감각 이해 |

### 4. 그림 4-2 전두엽 (p.49)
- 중심고랑 바로 앞 = 중심앞이랑 (Precentral gyrus) = 제1차 운동영역.
- 전두엽의 이랑은 3종: 상전두이랑 → 중전두이랑 → 하전두이랑 (외측면 A).
- 전두엽은 내측면(B)으로도 이어진다.
- 기저면(C)에서는 전두극과 안와전두피질이 잘 보인다.
- 범례: ① 중심앞이랑, ② 중전두이랑, ③ 하전두이랑 (원문 번호 상전두이랑 위치 [불확실]), 상전두이랑, ④ 안와전두피질, ⑤ 전두극.

### 5. 그림 4-3 하전두이랑과 덮개부 (p.50)
| 구조 | 내용 |
|---|---|
| 하전두이랑의 3부분 | 전두덮개부, 삼각부, 안와부 |
| 실비우스주위피질 (perisylvian cortex) | 전두덮개부 + 두정덮개부 + 측두덮개부 |

- 라벨: 중심고랑, 전두덮개부, 두정덮개부, 삼각부, 안와부, 측두덮개부, 실비우스주위피질.

### 6. 그림 4-4 두정엽 (p.50)
- 외측면(A)과 내측면(B) 모두: 중심고랑 → 중심뒤이랑 → (뒤로) 상두정소엽, 하두정소엽.
- 하두정소엽 안에 모서리위이랑 (supramarginal gyrus)과 각이랑 (angular gyrus).
- 라벨: 중심고랑, 두정후두고랑. 범례: 중심뒤이랑, 상두정소엽, ③ 모서리위이랑, ④ 각이랑.

```
중심고랑 → 중심뒤이랑 → 상두정소엽
                     → 하두정소엽 ⊃ 모서리위이랑 + 각이랑
```

### 7. 그림 4-5 측두엽 (p.51)
- 외측면(A): 실비안종렬 아래에 있는 엽.
- 상측두이랑의 가장 위, 실비안종렬 안쪽에 헤쉴이랑 (Heschl's gyrus).
- 하측두이랑은 내측면(B)에서 측면고랑 아래에 있고, 기저면(C)에서도 잘 보인다.
- 라벨: 실비안종렬, 헤쉴이랑, 후두앞패임, 측면고랑.
- 범례: ① 상측두이랑 (superior), ② 중측두이랑 (medial), ③ 하측두이랑 (inferior), ④ 측두극.

### 8. 그림 4-6 후두엽 (p.51)
- 후두앞패임과 두정후두고랑이 각각 측두엽·두정엽과 후두엽을 가른다.
- 라벨: 두정후두고랑, 후두앞패임, 새발톱고랑 (calcarine sulcus).
- 필기: 제1차 시각영역 — 연합영역 ([불확실]).

### 9. 그림 4-7 뇌섬 (insula) (p.52)
- 실비우스주위피질의 덮개부 안쪽에 위치한다.
- 외측면에서는 직접 볼 수 없다.

### 10. 그림 4-8 변연계 (limbic system) (p.52)
- 뇌 안쪽 깊숙이 있다.
- 구성: 유두체, 편도체, 해마, 갈고리이랑, 중격, 뇌궁, 띠이랑 등.
- 라벨: 띠고랑, 띠이랑, 중격, 유두체, 갈고리이랑, 편도체, 해마, 두정밀고랑 (원문 표기 [불확실]), 뇌궁, 측면고랑, 해마곁이랑.
- 기능: 감정, 기억, 집중 욕구 (필기).

### 11. 그림 4-9 대뇌의 기저면 (p.53, 사진 15)
- 좌우 대칭. 전두엽·측두엽 기저면 + 뇌교, 연수, 소뇌.
- A 라벨: 곧은이랑, 후각고랑, 후각망울, 후각로, 하측두고랑, 하측두이랑, 안와이랑, 안와고랑, 갈고리이랑, 해마곁이랑, 뇌교, 연수, 소뇌.
- B(가운데 확대) 라벨: 시신경, 시신경교차, 회백융기, 시각로, 대뇌각, 외측무릎체, 유두체, 뇌교, 동안신경(동안신경 = 눈돌림신경).
- (p.53은 사진 15 소속이지만 기저면 주제라서 여기에 둠. 같은 페이지의 수평면 그림 4-10은 4교시.)

## ⭐ 필기·강조 포인트
- p.49: 엽별 기능 (전두=사고·문제해결·추리·판단·욕구조절 / 측두=청각 / 후두=시각 / 두정=감각). 강조.
- p.49: 중심앞이랑 = Precentral gy = 제1차 운동영역. 강조.
- p.49: 이랑 gyrus(올라온 부분) / 고랑 sulcus(들어간 부분). 중심고랑은 앞뒤로 나눈다. 대뇌종렬은 좌우를 나눈다.
- p.49: 위치·모양은 개인차가 약간 있음.
- p.50: 상두정소엽 빨간색 표시 (강조). 모서리위이랑 = Supra marginal gy, 각이랑 = angular gy.
- p.51: 상·중·하측두이랑 3분류 (superior / medial / inferior temporal gy). 후두엽 = 시각 영역 (강조).
- p.52: 변연계 기능 = 감정, 기억, 집중 욕구 (강조).
- p.53: 그림 4-9 별표 2개 (라벨 암기 대상, 나머지 메모 [불확실]). 뇌교: 파란 화살표 "신경이 제일 많아서 중요함".

## 🧠 이해의 열쇠
- 중심고랑을 경계로 앞은 "운동", 뒤는 "감각"이다. 중심앞이랑 = 운동, 중심뒤이랑 = 감각(체성감각) [보충].
- 실비우스주위피질(전두·두정·측두 덮개부 주변)은 언어와 관련 있는 핵심 지역이다. 하전두이랑의 전두덮개부·삼각부는 말 산출(브로카 영역)에 해당한다 [보충]. 6교시·7교시에서 다시 만난다.
- 모서리위이랑·각이랑은 하두정소엽에 있고 읽기·언어 이해와 연결된다 [보충].
- 헤쉴이랑은 제1차 청각 피질 자리다 [보충]. 새발톱고랑 주변은 제1차 시각영역이다.
- 변연계(감정·기억)가 손상되면 기억·정서 문제가 생긴다. 전두엽(판단·욕구조절)이 손상되면 계획·충동 조절이 어렵다.
- 뇌교는 신경이 많이 지나가므로 중요하다 (교재 필기).

## 🔑 암기 장치
- 엽 기능: "전사(사고) 측청(청각) 후시(시각) 두감(감각)" → 전·측·후·두 순서로 사·청·시·감.
- 전두엽 이랑: 위→아래 "상·중·하". 측두엽도 "상·중·하".
- 하전두이랑 3부분: 덮개·삼각·안와 → "덮삼안".
- 중심 기준: 앞 = pre = 운동, 뒤 = post = 감각.
- 변연계 구성: "유·편·해·갈·중·뇌·띠" (유두체, 편도체, 해마, 갈고리이랑, 중격, 뇌궁, 띠이랑).

## ⚠️ 헷갈리는 함정
- 이랑(gyrus, 올라옴) vs 고랑(sulcus, 들어감).
- 중심고랑(앞뒤로) vs 대뇌종렬(좌우로) vs 실비안종렬(측두엽 위쪽 경계).
- 중심앞이랑(전두, 운동) vs 중심뒤이랑(두정, 감각).
- 모서리위이랑 (supramarginal) vs 각이랑 (angular): 둘 다 하두정소엽.
- 덮개부 3개: 전두덮개부(하전두이랑에 속함) / 두정덮개부 / 측두덮개부. 삼각부·안와부와 혼동하지 말 것.
- 뇌섬은 덮개부 안쪽이라 외측면에서 안 보인다.
- 헤쉴이랑은 상측두이랑의 위쪽, 실비안종렬 안쪽.

## ✏️ 확인 문제
1. 전두엽과 두정엽을 나누는 고랑은?
> [!answer]- 정답
> 중심고랑 (central sulcus).

2. 측두엽을 전두엽·두정엽에서 분리하는 구조는?
> [!answer]- 정답
> 실비안종렬 (외측고랑).

3. 후두엽을 다른 엽과 나누는 두 구조는?
> [!answer]- 정답
> 두정후두고랑과 후두앞패임.

4. 네 엽의 기능을 한 줄씩 쓰시오.
> [!answer]- 정답
> 전두엽: 사고력·문제해결·추리·판단·욕구조절. 측두엽: 청각 이해. 후두엽: 시각 이해. 두정엽: 감각 이해.

5. 중심앞이랑의 영어 이름과 기능은?
> [!answer]- 정답
> Precentral gyrus, 제1차 운동영역.

6. 하전두이랑의 세 부분과 실비우스주위피질을 이루는 세 덮개부는?
> [!answer]- 정답
> 전두덮개부·삼각부·안와부. 실비우스주위피질 = 전두덮개부+두정덮개부+측두덮개부.

7. 하두정소엽에 있는 두 이랑과 영어 이름은?
> [!answer]- 정답
> 모서리위이랑 (supramarginal gyrus), 각이랑 (angular gyrus).

8. 헤쉴이랑은 어디에 있는가?
> [!answer]- 정답
> 상측두이랑의 가장 위쪽, 실비안종렬 안쪽.

9. 변연계의 구성 구조 5개 이상과 기능은?
> [!answer]- 정답
> 유두체, 편도체, 해마, 갈고리이랑, 중격, 뇌궁, 띠이랑 중 5개. 기능: 감정, 기억, 집중 욕구.

10. 뇌 기저면 확대 그림(B)에 있는 라벨 중 시각 경로와 관련된 것은?
> [!answer]- 정답
> 시신경, 시신경교차, 시각로, 외측무릎체. (그 밖에 회백융기, 대뇌각, 유두체, 뇌교, 동안신경.)
