# 1교시. 신경계 큰 그림 (교재 p.33–39 · 권장 30분)
상위: [[프로젝트 컨텍스트]] · [[커리큘럼]] · 이전: 없음 · 다음: [[2교시 방향·보호구조·척수 경로]]

## 이번 시간 목표
- 뉴런(신경세포)의 구조와 운동/감각 신경세포의 차이를 말할 수 있다.
- 시냅스와 신경근접합부(아세틸콜린)를 그림 라벨까지 안다.
- 신경계 구분(CNS/PNS), 뇌의 구분(표 3-1), 척수 5부위와 신경 쌍수(12 + 31 = 43)를 외운다.

## 핵심 개념

### 1) 신경계 (p.33) — 그림 2-1 전형적인 운동신경세포
- 운동신경세포 = 세포체 + 축삭 + 수상돌기 + 축삭종말 등.
- 축삭의 끝은 다른 신경세포나 근육세포와 연결된다.
- **뉴런(neuron)** = 신경세포의 가장 작은 단위.
- 그림 라벨(전부):

| 부위 | 라벨 |
|---|---|
| 세포체 쪽 | 핵, 핵주위부, 세포체, 수상돌기 |
| 축삭 쪽 | 축삭, 랑비에마디, 미엘린수초, 축삭종말 |
| 연결 부위 | 신경연접(시냅스), 신경근접합부, 종말단추, 근육세포 |
| 방향 | 전도 방향 |

### 2) 신경세포 2종류 (p.33–34)

| 구분 | 운동신경세포 | 감각신경세포 |
|---|---|---|
| 방향 | 뇌 → 말초 (원심성) | 말초 → 중추 (상행 전도) |
| 구조 | 세포체가 축삭 끝에 위치 (그림 2-1) | 축삭과 수상돌기가 직접 연결, 세포체는 축삭 줄기에서 떨어진 곁에 위치 (그림 2-2) |
| 그림 2-2 라벨 | - | 수상돌기, 축삭, 세포체, 피부세포, 전도방향(피부 → 중추) |
- 필기: 언어는 "운동"에 해당한다.

### 3) 신경연접(시냅스) (p.34) — 그림 2-3
- 구성: **종말단추 + 연접틈새 + 연접후 수용기**.
- 종말단추 안에는 신경전달물질로 채워진 **연접소낭**이 있다.
- 라벨: 종말단추, 연접소낭, 연접틈새, 신경전달물질, 연접후 수용기.

### 4) 신경근육접합 (Neuromuscular Junction) (p.35) — 그림 2-4
- 운동신경세포 축삭종말의 종말단추가 근육세포와 접촉한다. 이 부위 = **신경근접합부**.
- 그림 2-4 라벨: 운동신경세포의 축삭종말, 연접소낭, 종말단추, 신경근접합부, 근육세포막, 근육세포, 운동종판.
- 영문 도판 라벨: Neuron, Synaptic vesicles, Endocytosis, Exocytosis active zone, **Acetylcholine**, Acetylcholine receptors, Neuropeptide modulators, Muscle.
- Acetylcholine = 신경전달물질 (필기).

### 5) Neuron 모식도와 신경계 구분 (p.36)
- 신경세포 사진 라벨: Cell body, Dendrite, Axon.
- 모식도 라벨: Dendrite, Axosomatic synapse, Cell body, Axon hillock, Axodendritic synapse, Axon, Myelin sheath, Axon collateral, Axoaxonic synapse, Synaptic terminals.

| 연접 이름 | 뜻 (이름 구조) |
|---|---|
| Axosomatic | 축삭 → 세포체 |
| Axodendritic | 축삭 → 수상돌기 |
| Axoaxonic | 축삭 → 축삭 |

- **그림 3-1 신경계의 구분**

```
신경계
├─ 중추신경계 CNS (뇌 + 척수)   ← 중추는 2개
└─ 말초신경계 PNS
    ├─ 체성신경계 ─ 뇌신경 (뇌 말초신경)
    │             └ 척수신경 (척수 말초신경)
    └─ 자율신경계 ─ 교감신경
                  └ 부교감신경
```

### 6) 회백질과 백질 (p.37) — 그림 3-2
- 뇌: 회백질 = 겉층(피질), 백질 = 속층. (속에 피질하 회백질도 있음)
- 척수: 백질 = 겉층, 회백질 = 속층.
- 척수 단면 라벨: White matter(백질), Dorsal horn(후각), Grey matter(회백질), Ventral horn(전각).

| | 겉 | 속 |
|---|---|---|
| 뇌 | 회백질 | 백질 |
| 척수 | 백질 | 회백질 |

### 7) 중추신경계통 — 그림 3-3 뇌의 구분 (p.38)
- 뇌 = **대뇌 + 뇌간 + 소뇌**.
- 대뇌 = 종뇌 + 간뇌. 뇌간 = 중뇌 + 뇌교 + 연수.
- 관상단면 라벨: White matter, Cerebral cortex, Corpus callosum, Caudate nucleus, Lateral ventricle, Internal capsule, Putamen, Globus pallidus, Thalamus, Hippocampus, Midbrain, Pons, Medulla.
- 필기: Lateral ventricle = 뇌실 (뇌척수액이 지나감 [불확실]).

### 8) 표 3-1 뇌의 주요 구분 (p.39)

| 대분류 | 소분류 | 구조 |
|---|---|---|
| 대뇌 | 종뇌 (telencephalon) | 대뇌피질, 피질하백질, 피질하회백질(기저핵) |
| 대뇌 | 간뇌 (diencephalon) | 시상, 시상하부, 시상상부, 시상밑부 |
| 뇌간 | 중뇌 (mesencephalon, midbrain) | - |
| 뇌간 | 뇌교 (metencephalon, pons) | - |
| 뇌간 | 연수 (myencephalon, medulla oblongata, medulla) | - |
| 소뇌 | (소뇌) | - |

### 9) 척수의 종단 부위 (p.39) — 그림 3-4
- 척수는 위 → 아래 5부위. 각 부위에 척수신경이 쌍으로 연결된다.

| 척수 부위 | 위치 | 척수신경 | 쌍수 |
|---|---|---|---|
| 경수 | 목 | 경신경 | 8쌍 |
| 흉수 | 가슴 | 흉신경 | 12쌍 |
| 요수 | 허리 | 요신경 | 5쌍 |
| 천수(선수) | 그 아래 | 천골신경 | 5쌍 |
| 미수 | 가장 끝 | 미골신경 | 1쌍 |
- 합계 8 + 12 + 5 + 5 + 1 = **31쌍**.
- 그림 라벨: 척추, 척수신경.

## ⭐ 필기·강조 포인트
- p.33: 뉴런 = 신경세포의 가장 작은 단위. 신경세포 2종류(운동/감각). **언어는 운동에 해당**. 운동 = 뇌 → 말초(원심성), 감각 = 말초 → 중추(상행).
- p.35: Acetylcholine = 신경전달물질.
- p.36: 중추 = 2개 (1 뇌, 2 척수). 말초 = 체성(1) + 자율(2). 뇌신경 = "뇌 말초신경", 척수신경 = "척수 말초신경". (CNS/PNS 구분 별표)
- p.37: 뇌 = 겉 회백질/속 백질, 척수 = 겉 백질/속 회백질. 후각(Dorsal) / 전각(Ventral).
- p.38: **뇌간 = 중뇌 + 뇌교 + 연수 (3부분, 뇌줄기)**. 별표 + 주황 형광펜.
- p.39: **말초신경 43쌍 = 뇌 12쌍 + 척수 31쌍**. 대뇌 = 종뇌 + 간뇌 (빨간 별). 뇌간 빨간 별, 중뇌·뇌교·연수 형광펜. 중뇌에 빨간 동그라미 + X 표시 (의미는 교재 확인 필요).

## 🧠 이해의 열쇠
- 구조 → 기능: 수상돌기가 받고, 세포체가 처리하고, 축삭이 보내고, 종말단추가 전달물질을 낸다.
- 말하기는 운동이다. 뇌의 운동 명령이 운동신경 → 근육으로 간다. 이 길이 끊기면 말운동이 약해진다.
- 신경근접합부에서 아세틸콜린이 근육을 움직인다. [보충] 이 전달이 방해되면 근육이 약해진다 (예: 중증근무력증).
- 말초신경 중 뇌신경 12쌍이 얼굴·입·목 근육과 감각을 맡는다. [보충] 말, 삼킴과 직접 관련된다.
- 뇌간(중뇌·뇌교·연수)은 뇌신경이 나오는 길목이다. [보충] 연수 손상은 구음·삼킴 장애로 이어질 수 있다.

## 🔑 암기 장치
- 뇌간 = "중·교·연" (중뇌-뇌교-연수, 위에서 아래).
- 쌍수: 뇌 12 + 척수 31 = 43. 척수 8-12-5-5-1 ("팔-십이-오-오-일").
- 시냅스 3요소: 종 · 연 · 수 (종말단추, 연접틈새, 수용기).
- 겉/속: 뇌는 "겉이 회색(피질)", 척수는 "겉이 흰색".

## ⚠️ 헷갈리는 함정
- 체성신경계 vs 자율신경계: 체성 = 뇌신경 + 척수신경. 자율 = 교감 + 부교감.
- 뇌신경(12쌍)은 말초신경이다. 뇌 속 구조가 아니라 뇌에서 나온 말초신경이다.
- 종뇌 vs 간뇌: 둘 다 대뇌. 간뇌 = 시상, 시상하부 등.
- 뇌교는 표에서 metencephalon, 연수는 "myencephalon"으로 적혀 있다 (교재 표기. 표준은 myelencephalon, 교재 확인 필요).
- 척수 회백질은 속, 뇌 회백질은 겉.
- 천수 = 선수(같은 말). 신경 이름은 천골신경.

## ✏️ 확인 문제
1. 신경세포의 가장 작은 단위를 무엇이라 하는가?
> [!answer]- 정답
> 뉴런(neuron).

2. 운동신경세포와 감각신경세포의 전도 방향은?
> [!answer]- 정답
> 운동 = 뇌 → 말초 (원심성). 감각 = 말초 → 중추 (상행).

3. 그림 2-3 신경연접의 세 구성 요소는?
> [!answer]- 정답
> 종말단추, 연접틈새, 연접후 수용기. (종말단추 안에 연접소낭이 있다.)

4. 신경근접합부의 신경전달물질은?
> [!answer]- 정답
> 아세틸콜린(Acetylcholine).

5. 중추신경계와 말초신경계는 각각 무엇으로 이루어지는가?
> [!answer]- 정답
> 중추 = 뇌 + 척수. 말초 = 체성(뇌신경, 척수신경) + 자율(교감, 부교감).

6. 뇌와 척수에서 회백질/백질의 위치를 비교하라.
> [!answer]- 정답
> 뇌: 겉 회백질, 속 백질. 척수: 겉 백질, 속 회백질.

7. 뇌간을 이루는 3부분은?
> [!answer]- 정답
> 중뇌, 뇌교, 연수.

8. 종뇌에 속하는 구조 3가지와 간뇌에 속하는 구조는?
> [!answer]- 정답
> 종뇌 = 대뇌피질, 피질하백질, 피질하회백질(기저핵). 간뇌 = 시상, 시상하부, 시상상부, 시상밑부.

9. 척수 5부위와 각 신경 쌍수는?
> [!answer]- 정답
> 경수 8, 흉수 12, 요수 5, 천수 5, 미수 1 = 31쌍. 뇌신경 12쌍 + 31 = 말초신경 43쌍.

10. 모식도의 Axoaxonic synapse는 무엇과 무엇의 연접인가?
> [!answer]- 정답
> 축삭과 축삭의 연접. (Axosomatic = 축삭-세포체, Axodendritic = 축삭-수상돌기)
