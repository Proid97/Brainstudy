# 7교시. 뇌기능 2 운동·언어·고차기능 (교재 p.85–87 · 권장 35분)
상위: [[프로젝트 컨텍스트]] · [[커리큘럼]] · 이전: [[6교시 뇌기능 1 연구방법·브로드만·감각]] · 다음: [[모의고사]]

## 이번 시간 목표
- 일차운동영역(BA4), 전운동영역(BA6·8), 브로드만영역(BA44·45)의 위치와 손상 증상을 구분한다.
- 뇌섬(BA15), 상두정소엽(BA5·7), 띠이랑, 전전두엽의 기능과 손상 증상(전도실어증, 관념운동실행증, 무동성 함구증)을 말한다.
- 미각(BA43), 후각(BA28 앞), 감정(변연계)과 그림 5-5의 두정엽 연결을 이해하고, 6·7교시 BA를 한 표로 정리한다.

## 핵심 개념

### 1. 측두엽의 이질양식 연합기능 (p.85)
- 측두엽은 청각연합영역 외에는 정확히 이질양식 연합영역으로 분류되지 않는다.
- 그래도 청각에만 국한된 단양식 기능이 아닌 기능을 한다.
- **BA37 = 방추형이랑(fusiform gyrus)**.
| 손상 쪽 | 증상 |
|---|---|
| 좌반구 BA37 | 실독증, 연결피질감각실어증(transcortical sensory aphasia) |
| 우반구 BA37 | 시지각장애 |
| 양반구 BA37 | 얼굴실인증 |

### 2. 말기관 운동과 마비말장애 (p.85)
- **일차운동영역 = BA4**. 전두엽 **중심앞이랑**.
- 체감각 호문쿨러스처럼, 신체 부위별로 뇌의 특정 영역이 운동을 담당한다 = **운동 호문쿨러스**.
- 그림 5-4: BA4는 신체 부위별로 운동기능을 내려보내는 국소해부학적 구조.
- 그림 라벨(일부 불확실): 엉덩이, 몸통, 어깨, 팔꿈치, 손목, 손, 손가락(새끼·약지 계열), 목, 이마, 눈꺼풀과 눈동자, 얼굴, 입술, 턱, 혀, 후두(인두), 무릎, 발목, 발가락.
- 소제목은 "말기관 운동과 마비말장애"다. 이 쪽에 마비말장애 증상 설명 문장은 없다 [원문에 없음].

### 3. 말운동 프로그래밍과 말실행증 (p.85)
- 일차운동영역이 명령을 내리기 **전에**, 전두엽 **BA6, BA8(전운동영역)**에서 말운동을 조직·프로그래밍한다.
- 전운동영역, 특히 **보충운동영역 BA6** 손상 → 복잡한 운동 수행장애 + 일련의 말움직임·프로그래밍 장애 = **말실행증(apraxia of speech)**.
- **뇌섬(BA15)**도 말실행증을 일으키는 영역에 포함된다. 특히 **좌측 앞뇌섬(BA15)** 손상에서 관찰된다.

### 4. 언어표현과 브로카실어증 (p.85–86)
- **BA44 + BA45 = 브로카영역(Broca's area)** = 표현언어중추.
- 손상 → 브로카실어증:
  - 발화 길이가 짧고 조사 누락 = **실문법증(agrammatism)** (교재 표기 "agrmmatism" 오탈자).
  - 운율이 단조로움 = **실율증(aprosodia)**.
- **BA44** 손상 → **발성실행증(apraxia of phonation, AOP)**. (p.86에서 이어짐)

### 5. 따라말하기와 전도실어증 (p.86)
- **BA15 = 뇌섬**. 실비우스 주위피질 중심에 있다.
- 전두엽·두정엽·측두엽의 **덮개부 안쪽**에 있어서 측두엽과 전두엽을 잇는 **연결섬유의 통로** 역할을 한다.
- 뇌섬 손상 → **전도실어증(conduction aphasia)**.

### 6. 동작처리와 실행증 (p.86)
- **BA5, BA7 = 상두정소엽** = 체감각연합영역.
- **좌반구**에는 특정 목적을 위한 **동작사전**이 저장되어 있다.
- 손상 → 지시받은 동작·행동을 못 함 = **관념운동실행증(ideomotor apraxia)**.

### 7. 고등기능처리와 장애 (p.86)
- 전두엽에서 일차운동영역과 전운동영역을 **뺀 앞쪽 전체** = **전전두엽(prefrontal cortex)**.
- 측두엽, 두정엽, 후두엽, 변연계와 연계. 고등기능, 판단, 문제해결에 관여.
- 따라서 전전두엽은 **이질양식 연합영역**이다.

### 8. 행동개시와 무의지증 (p.86)
- **띠이랑(cingulate gyrus)**: 앞과 뒤로 나뉜다.
  - 앞: **BA24, BA32, BA33**.
  - 뒤: **BA23, BA31**.
- 손상 → 무의지증.
- **좌우반구 앞부분 띠이랑** 손상 → 영구적 **무동성 함구증(akinetic mutism)**.

### 9. 미각·후각 (p.86)
- **일차미각영역 = BA43**. 두정덮개부(parietal operculum). 실비안종렬 바로 위.
- **BA28 앞부분** = 해마곁이랑(측두엽 내측면) = **일차후각영역**.

### 10. 감정처리 (p.86)
- 변연계의 또 다른 주요 역할: **기분·정동 조절**.
- 손상 → 기분조절 능력 저하, 정동장애, 감정적 불안정성. 갑자기 울다가 웃기도 한다.

### 11. 그림 5-5 두정엽과 다른 뇌엽 간의 연결 (p.87)
- 두정엽 연합영역과 다른 뇌엽은 끊임없이 기능적으로 연결되어 신호를 주고받는다.
- 화살표 1: 각 뇌엽의 일차·이차영역 또는 단양식 연합영역 → **두정엽의 이질양식 연합영역**(점/원 표시)으로 정보가 모이는 방향.
- 화살표 2: 운동신호가 **전전두엽영역들**로 전달되는 방향.
- 라벨: 중심고랑.

## 🧠 이해의 열쇠
**말이 나오는 길(운동 위계)**
- 계획: 전운동영역 BA6·8 (어떤 순서로 움직일지 짠다).
- 실행: 일차운동영역 BA4 (근육에 명령을 보낸다).
- 계획이 망가지면 근육은 멀쩡한데 순서가 틀린다 = **말실행증**.
- 근육 명령 자체가 약하면 = 마비말장애(소제목만 교재에 있음).
- 언어 단계는 또 다르다. 브로카(44·45)는 **언어 표현**(문법·운율)이다. 실행증과 구분한다.

**수준별 손상 비교**
| 수준 | 예 | 증상 |
|---|---|---|
| 일차 | BA4 | 해당 신체 운동 문제 [보충] |
| 연합(계획) | BA6·8, BA5·7(좌) | 말실행증, 관념운동실행증 |
| 이질양식 | 전전두엽, BA37, 39·40 | 고등기능, 언어·인식 복합 문제 |

- 전도실어증: 뇌섬이 측두엽(이해)과 전두엽(표현)을 잇는 다리라서, 다리가 끊기면 따라말하기가 어렵다. 교재 소제목이 "따라말하기와 전도실어증"이다.
- 띠이랑: "하고자 하는 의지"를 시작시킨다. 양쪽 앞띠이랑이 나가면 의지가 꺼져서 움직임·말이 멈춘다(무동성 함구증).
- 변연계: 기억(6교시)과 정서(7교시)를 함께 담당한다.
- [보충] 실어증은 언어 자체, 실행증은 학습된 동작 계획, 실인증은 감각 인식의 장애다.
- [보충] 뇌섬을 BA15로 쓰는 것은 교재 표기를 따른 것이다. 시험은 교재대로 답한다.

## 🔑 암기 장치
- **BA4 = 사(4)고 싶다 → 움직임**: 4번은 일차운동. "4 = 실행".
- **BA6 → 8**: 6·8은 "계획": 여섯 번 여덟 번 연습해서 프로그램.
- **BA44·45 = 사사·사오 → "말(4·5)하는 브로카"**: 44는 발성(AOP), 45는 문법 쪽(순서로 44 → 45, 소리 → 문장 [보충 연상]).
- **BA39 = 각이랑, BA40 = 모서리위이랑**: 하두정소엽 쌍둥이. 게르트만.
- **BA5·7**: 상두정소엽, 좌 = 동작사전.
- **띠이랑 앞 = 24·32·33, 뒤 = 23·31**: "앞은 셋(24·32·33), 뒤는 둘(23·31)". 숫자 개수가 3 vs 2.
- **BA43 = 미각**: "43(사삼) = 사(4)탕 삼(3)키는 맛".
- **BA28 앞 = 후각, 뒤 = 기억**.
- **BA15 = 뇌섬 = 다리(전도)**: "십오(15)분 걸리는 다리".

## ⚠️ 헷갈리는 함정
| 헷갈림 | 구분 |
|---|---|
| BA4 vs BA6 | 4는 일차운동(중심앞이랑, 명령 실행). 6은 전운동·보충운동(계획) |
| BA6 vs BA8 | 둘 다 전운동. 교재 증상은 BA6(보충운동영역)만 구체적으로 기술 |
| BA44 vs BA45 | 둘 합쳐 브로카영역. 교재 구분은 BA44 손상 → 발성실행증(AOP) |
| 39 vs 40 | 39 각이랑, 40 모서리위이랑. 증상 목록은 함께 기술(좌/우로 구분) |
| 5·7 vs 39·40 | 5·7 상두정소엽(체감각연합), 39·40 하두정소엽(이질양식) |
| 말실행증 vs 브로카실어증 | 실행증: 프로그래밍 장애(BA6, 좌 앞뇌섬). 브로카: 표현언어 장애(BA44·45), 실문법증·실율증 |
| 말실행증 vs 발성실행증 | 말실행증은 BA6·뇌섬. 발성실행증(AOP)은 BA44 |
| 관념운동실행증 vs 말실행증 | 관념운동: 지시 동작 수행 못 함(BA5·7 좌). 말실행증: 말 프로그래밍 |
| 실인증 vs 실어증 vs 실행증 | 인식(감각) / 언어 / 동작 수행 |
| 전도실어증 vs 연결피질감각실어증 | 전도: 뇌섬(BA15)/따라말하기. 연결피질감각: 좌 BA37 |
| 일차미각 BA43 vs 일차후각 BA28 앞 | 43은 두정덮개부, 28 앞은 측두엽 내측면 |
| 앞띠이랑 vs 뒤띠이랑 | 앞 24·32·33, 뒤 23·31. 무동성 함구증은 양쪽 앞부분 |
| BA37 6교시 vs 7교시 | 6교시: 시각기억. 7교시: 방추형이랑 증상(실독증, 얼굴실인증) |

## ✏️ 확인 문제
**1.** 환자: 말이 짧고 조사를 빼먹는다. 억양이 단조롭다. 손상 BA와 증상 이름은?
> [!answer]- 정답
> BA44·45(브로카영역). 브로카실어증: 실문법증과 실율증.

**2.** 브로카영역 중 어느 BA 손상이 발성실행증을 일으키는가?
> [!answer]- 정답
> BA44.

**3.** 환자: 근력은 정상이나 복잡한 말움직임의 순서를 만들지 못한다. 손상 부위 2곳 이상은?
> [!answer]- 정답
> 전운동영역 BA6(보충운동영역), BA8. 또는 좌측 앞뇌섬(BA15). 말실행증.

**4.** 환자: 상대 말을 이해하고 말도 하지만 따라말하기가 안 된다. 부위는?
> [!answer]- 정답
> 뇌섬(BA15). 측두엽과 전두엽을 잇는 연결섬유 통로. 전도실어증.

**5.** 환자: "손을 흔들어 보세요"라고 하면 못 한다. 좌반구 손상이다. 부위와 증상은?
> [!answer]- 정답
> 상두정소엽 BA5·7(동작사전). 관념운동실행증.

**6.** 환자: 가족 얼굴을 알아보지 못한다. 양쪽 측두엽 손상이다. BA는?
> [!answer]- 정답
> BA37(방추형이랑). 얼굴실인증.
