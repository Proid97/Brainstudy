# 4교시. 대뇌 속구조 (교재 p.53–60 · 권장 35분)
상위: [[프로젝트 컨텍스트]] · [[커리큘럼]] · 이전: [[3교시 대뇌겉질 엽과 이랑]] · 다음: [[5교시 MRI 단면 읽기]]

## 이번 시간 목표
- 수평면·관상면·내측면 그림의 속구조 라벨(뇌량, 내포, 전장, 기저핵 등)을 외운다.
- 기저핵과 시상의 구성, 핵군 이름, 무릎체의 기능을 구분한다.
- 내포의 부위별 담당(무릎 = 얼굴, 후각 = 몸통·사지)을 말할 수 있다.

## 핵심 개념

### 1. 그림 4-10 뇌의 수평면 (p.53)
- 피질(회백질층)과 백질, 그리고 피질하 구조가 보인다. 방향: 앞 / 뒤.
- 라벨 전체:

| 영역 | 라벨 |
|---|---|
| 뇌실 | 외측뇌실(전각), 외측뇌실(후각), 맥락얼기 |
| 기저핵 | 꼬리핵(머리), 꼬리핵(꼬리), 조가비핵, 창백핵(외측), 창백핵(내측) |
| 피질 쪽 | 뇌섬, 극포, 전장(claustrum), 외포 |
| 내포 | 내포(전각), 내포(무릎), 내포(후각) |
| 뇌량 | 뇌량(무릎), 뇌량(팽대) |
| 기타 | 시상 (필기) |

- 바깥에서 안으로 겹: 뇌섬 → 극포 → 전장 → 외포 → 조가비핵 → 창백핵 → 내포 (그림 4-16 순서와 일치).

### 2. 그림 4-11 내포(internal capsule)의 부위별 대응 (p.54)
| 내포 부위 | 담당 |
|---|---|
| 전각 | (교재 설명 없음) |
| 무릎 | 구성(협)얼굴(buccofacial) 영역 |
| 후각 | 몸통과 사지 |

- 운동·감각 신경이 많이 지나간다 (필기).

### 3. 기저핵 (basal ganglia, BG) (p.54)
- 피질하의 커다란 핵군. 운동을 담당 (필기).

```
꼬리핵 (머리+몸체+꼬리)
조가비핵 (putamen)        ┐ 렌즈핵 (조가비핵 + 창백핵)
창백핵 (globus pallidus)  ┘
줄무늬핵 (선조핵, striatum) = 꼬리핵 + 조가비핵
```

### 4. 그림 6.1·6.2 뇌저신경절 (p.56 삽입 자료)
- 6.1 뇌저신경절과 국소연결: Thalamus, Pallidum, Putamen, Caudate nucleus, Amygdaloid nucleus.
  - 각주: 1) 시상 2) 담창구 3) 편도핵 4) 미상핵 5) 피각.
  - 라벨 번호와 각주 번호의 대응이 어긋나 보임 [불확실].
- 6.2 뇌저신경절과 뇌실: Head of caudate nucleus(미상핵두부), Putamen(피각), Subthalamic nucleus(시상밑핵), Amygdaloid nucleus(편도핵), Tail of caudate nucleus(미상핵미부), Thalamus(시상), Lateral ventricle(측뇌실).
- 용어 대응: 미상핵 = 꼬리핵, 피각 = 조가비핵, 담창구 = 창백핵.

### 5. 시상 (thalamus)과 간뇌 (p.55)
| 간뇌의 구성 | 내용 |
|---|---|
| 시상상부 (epithalamus) | 후각, 생식기능, 수면 |
| 시상 (thalamus) | 간뇌에서 가장 큼, 약 4cm |
| 시상밑부 (subthalamus) | - |
| 시상하부 (hypothalamus) | 변연계의 일부 |

- 교재 표기는 "간뇌(midbrain)". 필기에서 midbrain에 취소선, "간뇌"에 동그라미 ([불확실]). 간뇌 = diencephalon, midbrain = 중뇌 (교재 확인 필요).
- 시상: 대뇌피질 바로 아래, 제3뇌실을 가운데 두고 1쌍.
- 기능: 감각정보와 운동정보를 대뇌피질로 연결하는 중계역할.
- 뇌하수체 (hypophysis): 시상하부 중 가장 아랫부분. 체온, 혈관운동, 신진대사, 수면, 소화관 등 내분비 기능 조절.
- 그림 4-12: 시상은 꼬리핵 등 기저핵 구조와 접한다. 라벨: 시상, 꼬리핵의 머리, 렌즈핵(조가비핵+창백핵), 꼬리핵의 꼬리.

### 6. 그림 4-13 시상과 핵군 (p.57)
- A 라벨: 시상, 꼬리핵(꼬리), 조가비핵, 소뇌, 창백핵(투영되어 보이는 핵), 꼬리핵(머리). (원문 '칭백핵' 은 창백핵의 오기로 보임, 교재 확인 필요.)
- B 핵군 11개:

| 위치 | 핵 |
|---|---|
| 앞 | 앞핵 |
| 배쪽 | 배쪽앞핵, 배쪽외측핵, 배쪽뒤외측핵, 배쪽뒤내측핵 |
| 등쪽 | 등쪽외측핵, 등쪽내측핵 |
| 뒤 | 뒤외측핵, 시상베개 |
| 무릎체 | 외측무릎체, 내측무릎체 |

- 외측무릎체 = 시각정보, 내측무릎체 = 청각정보 (필기).
- 그림 4-14 시상피질로: 시상 핵군이 시상피질로를 통해 피질의 여러 구조와 연결된다 (같은 11개 핵 라벨). 필기: 후두엽 쪽 화살표 "보고 → 해석, 시각영역·연합영역" ([불확실]).

### 7. 그림 4-15 뇌의 내측면 (p.58)
- 가장 중심에 뇌량. 라벨:

| 영역 | 라벨 |
|---|---|
| 전두·두정 | 중심고랑, 중심곁소엽, 상전두이랑, 띠고랑, 띠이랑, 쐐기앞소엽, 두정후두고랑 |
| 후두 | 쐐기소엽, 설상이랑, 새발톱고랑 |
| 깊은 구조 | 중격, 뇌량, 뇌궁 |
| 측두 쪽 | 갈고리이랑, 방추형이랑, 해마곁이랑, 측면고랑 |

- 뇌량: 신경섬유다발, 좌우 뇌가 정보를 주고받음 (필기, 판독 [불확실]).

### 8. 그림 4-16 뇌의 관상면 (p.58)
- 외측뇌실 같은 좌우 대칭 구조, 뇌량, 중격, 전교련이 관찰된다.
- 라벨: 뇌량, 외측뇌실, 중격, 전교련, 편도핵, 꼬리핵(머리), 내포(전각), 뇌섬, 극포, 전장, 외포, 조가비핵, 창백핵(내측), 창백핵(외측).

### 9. 변연계·뇌섬 (p.52, 3교시에서 다룸)
- 변연계: 유두체, 편도체, 해마, 갈고리이랑, 중격, 뇌궁, 띠이랑. 기능: 감정, 기억, 집중 욕구.
- 시상하부는 변연계의 일부 (p.55).
- 뇌섬은 실비우스주위피질 덮개부 안쪽에 있고, 수평면·관상면에서 보인다.

| 그림 | 라벨 |

## ⭐ 필기·강조 포인트
- p.53: 그림 4-9, 4-10에 별표 (라벨 암기). 그림 안에 "기저핵"(꼬리핵 부위), "시상" 표기. 뇌교는 신경이 제일 많아서 중요.
- p.54: 기저핵(basal ganglia) 빨간 별, "BG", "운동을 담당".
- p.54: 내포: buccofacial의 "얼굴" 동그라미, "(운동, 감각) 신경이 많이 지나감".
- p.55: "간뇌" 동그라미, "1쌍" 동그라미, "중계역할" 밑줄. 강조: 간뇌, 1쌍, 중계역할.
- p.57: 외측무릎체 = 시각, 내측무릎체 = 청각 (강조).
- p.58: 뇌량 = 좌우 뇌 정보 교환. 그림 4-16 빨간 별 (강조).
- p.59: B-MRI 밑줄.

## 🧠 이해의 열쇠
- 내포는 대뇌피질과 아래쪽(뇌간·척수)을 잇는 신경섬유의 좁은 통로다. 여기가 다치면 한쪽 얼굴과 팔다리가 함께 마비될 수 있다 [보충]. 무릎 = 얼굴이라서 말(구어) 근육 조절과 연결된다.
- 기저핵은 운동의 시작·조절·크기에 관여한다. 손상되면 파킨슨병처럼 말이 작고 단조로워질 수 있다 [보충].
- 시상은 감각의 중계소다. 외측무릎체 → 시각, 내측무릎체 → 청각으로 길이 나뉜다.
- 뇌량은 두 반구를 이어서 좌우 정보를 교환한다.
- 시상하부·뇌하수체는 체온·대사·수면 같은 몸 상태 조절을 맡는다.
- 변연계(해마, 편도체 등)는 감정과 기억이다 (3교시 연결).

## 🔑 암기 장치
- 바깥→안 겹: "뇌·극·전·외·조·창·내" (뇌섬, 극포, 전장, 외포, 조가비핵, 창백핵, 내포).
- 렌즈핵 = 조가비 + 창백 (렌즈 = "조창"). 줄무늬핵 = 꼬리 + 조가비.
- 내포: 전각·무릎·후각 → 무릎 = 얼굴(구강·안면), 후각 = 몸·팔다리.
- 무릎체: 외측 = 눈(시각), 내측 = 귀(청각). "외시 내청".
- 일본식 용어 대응: 미상 = 꼬리, 피각 = 조가비, 담창구 = 창백.
- 간뇌 4부: 상부·시상·밑부·하부 (시상상부 / 시상 / 시상밑부 / 시상하부).

## ⚠️ 헷갈리는 함정
- 간뇌(diencephalon) vs 중뇌(midbrain): 교재 표기 오류를 필기에서 수정함.
- 극포 vs 전장 vs 외포: 전장(claustrum)은 얇은 회백질 층, 극포·외포는 그 양쪽 백질 [보충]. 그림 라벨 순서로 외움.
- 렌즈핵(조가비+창백) vs 줄무늬핵(꼬리+조가비).
- 외측무릎체(시각) vs 내측무릎체(청각).
- 시상(thalamus) vs 시상하부(hypothalamus) vs 시상밑부 vs 시상상부.
- 뇌량(무릎/팽대) vs 내포(무릎): 이름만 같고 다른 구조.
- 시상베개는 핵 이름 (베개 모양), 뇌 베개가 아님.

## ✏️ 확인 문제
1. 내포의 무릎과 후각은 각각 무엇을 담당하는가?
> [!answer]- 정답
> 무릎: 구성(협)얼굴 영역. 후각: 몸통과 사지.

2. 이 부위가 손상되면? 내포 무릎.
> [!answer]- 정답
> 얼굴·구강 쪽 운동 조절 문제 (교재: 얼굴 영역 담당). 운동·감각 신경이 많이 지나가는 통로다.

3. 기저핵을 이루는 세 핵은? 렌즈핵과 줄무늬핵은?
> [!answer]- 정답
> 꼬리핵, 조가비핵, 창백핵. 렌즈핵 = 조가비핵+창백핵. 줄무늬핵 = 꼬리핵+조가비핵.

4. 미상핵·피각·담창구는 각각 무엇인가?
> [!answer]- 정답
> 꼬리핵·조가비핵·창백핵의 다른 이름.

5. 간뇌를 이루는 4부분은?
> [!answer]- 정답
> 시상상부, 시상, 시상밑부, 시상하부.

6. 시상의 특징 4가지는?
> [!answer]- 정답
> 약 4cm, 간뇌에서 가장 큼, 제3뇌실을 가운데 두고 1쌍, 감각·운동정보를 대뇌피질로 보내는 중계역할.

7. 외측무릎체와 내측무릎체의 기능은?
> [!answer]- 정답
> 외측무릎체: 시각정보. 내측무릎체: 청각정보.

8. 뇌량은 어떤 구조이고 무슨 일을 하는가? 수평면에서 보이는 두 부분은?
> [!answer]- 정답
> 좌우 뇌를 잇는 신경섬유다발로 정보를 주고받는다. 뇌량(무릎)과 뇌량(팽대).

9. 수평면에서 뇌섬 안쪽으로 이어지는 층을 바깥에서 안으로 쓰시오.
> [!answer]- 정답
> 뇌섬 → 극포 → 전장 → 외포 → 조가비핵 → 창백핵 → 내포 (관상면 라벨 순서 기준).

10. 시상하부에서 가장 아랫부분과 그 기능은?
> [!answer]- 정답
> 뇌하수체. 체온, 혈관운동, 신진대사, 수면, 소화관 등 내분비 기능 조절.
